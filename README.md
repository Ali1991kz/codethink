# CODE → THINK

7–8 сынып оқушыларының Python есептері арқылы алгоритмдік ойлауы мен функционалдық сауаттылығын дамытуға арналған толық веб-платформа.

## Мүмкіндіктер

- мұғалім және оқушы аккаунттары;
- сынып құру және оқушыны тіркеу;
- 7–8 сыныпқа арналған бастапқы және қорытынды диагностика;
- бес кезеңді CODE THINK моделі: Түсін → Жоспарла → Кодта → Тексер → Түсіндір және қолдан;
- браузерде Python кодын орындау;
- авторлық әдістемелік құралдағы 31 есептік тапсырмалар банкі және сыныпқа тапсырма беру;
- мұғалімнің бағалауы мен кері байланысы;
- жеті көрсеткіш бойынша алгоритмдік ойлау профилі;
- оқушының жеке кабинеті, тапсырмалары, ұсыныстары және өсу динамикасы;
- мұғалімге сыныптық аналитика және әр оқушының қысқаша прогресі;
- қауіпсіз уақытша құпиясөзді автоматты жасау және бір рет көрсету;
- Excel шаблоны арқылы оқушыларды сыныптарымен жаппай тіркеу және логин-құпиясөз нәтижесін Excel түрінде жүктеу;
- оқушы тіркелген сынып деңгейіне сәйкес тапсырмаларды автоматты жариялау;
- Excel CSV және PDF есебі;
- жоба туралы, нұсқаулық және қазыларға арналған дерексіз демо режим;
- академиялық адалдық оқиғалары.

## Технологиялар

- Frontend: HTML, CSS, JavaScript;
- Python: Pyodide Web Worker;
- Backend: Google Apps Script;
- Database: Google Sheets;
- Hosting: GitHub Pages және custom domain;

## Іске қосу

Толық қадамдар: [docs/INSTALLATION_KK.md](docs/INSTALLATION_KK.md)

Қысқаша:

1. Google Sheets кестесін ашыңыз.
2. Extensions → Apps Script арқылы `google-apps-script/Code.gs` кодын салыңыз.
3. `setupSystem()` функциясын орындаңыз.
4. Web App ретінде жариялап, `/exec` сілтемесін көшіріңіз.
5. Сілтемені `config.js` файлына енгізіңіз.
6. Осы қалтаның frontend файлдарын GitHub репозиторийіне жүктеп, GitHub Pages қосыңыз.

Оқыту циклі аяқталған кезде мұғалім панеліндегі **Қорытындыны ашу** батырмасы арқылы қорытынды диагностиканы іске қосады.

## 5.0 нұсқасына жаңарту

1. Apps Script ішіндегі ескі кодты жаңа `google-apps-script/Code.gs` кодымен ауыстырыңыз.
2. **Deploy → Manage deployments → Edit → New version → Deploy** арқылы Web App-ты жаңартыңыз.
3. Google кестені қайта жүктеп, **CODE THINK → Әдістемелік құрал есептерін қосу** пәрменін бір рет басыңыз.
4. Сайтқа кіріп, **Мұғалім → Басқару → Тапсырмалар банкі** бөлімінен есептерді тексеріңіз.

Импортты қайта басуға болады: 31 есеп `sourceKey` арқылы тексеріледі және қайталанып қосылмайды. Бұрынғы тапсырмалар өшірілмейді.

## Оқушыларды Excel арқылы тіркеу

1. **Мұғалім → Оқушылар → Excel шаблонын жүктеу** батырмасын басыңыз.
2. `Оқушылар` парағына аты-жөні, логині, 7 немесе 8 деңгейі және сынып атауын енгізіңіз.
3. Құпиясөзді бос қалдырсаңыз, жүйе уақытша құпиясөзді өзі жасайды.
4. Толтырылған файлды сайттан таңдап, **Оқушыларды тіркеу** батырмасын басыңыз.
5. Импорт аяқталған соң логиндер, уақытша құпиясөздер және әр жолдың нәтижесі жазылған Excel файлы жүктеледі.

Оқушы сыныпқа тіркелген сәтте оның деңгейіне сәйкес барлық белсенді тапсырма автоматты түрде жарияланады. Мұғалім оларды бір-бірден тағайындамайды.

## Маңызды

Оқушыға Google кестені ашпаңыз. Web App жариялағанда **Execute as: Me**, **Who has access: Anyone** параметрлерін таңдаңыз. Платформа API сұрауларының барлығында сессияны және рөлді өзі тексереді.
